# 🍽️ Restaurant Data Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing a restaurant dataset using SQL to extract meaningful business insights.  
The dataset contains information about restaurant names, locations, ratings, and cost, which helps in understanding customer preferences and market trends.

## 📊 Dataset Description
The dataset includes the following columns:

- **Name** → Restaurant name  
- **City** → Location of the restaurant  
- **Rating Count** → Number of users who rated the restaurant  
- **Rating** → Average rating given by customers  
- **Cost** → Approximate cost for dining
- 
## 🎯 Objectives
The main goals of this project are:

- Analyze top-performing restaurants based on ratings and revenue  
- Identify cities with the highest number of restaurants  
- Understand customer rating behavior  
- Explore cost distribution across different restaurants  

## 📈 Key Analysis Performed
- Top 10 restaurants by total revenue  
- Average rating of restaurants by city  
- Number of restaurants available in each city  
- Restaurants with highest rating counts  
- Cost-based restaurant comparison  

## 🛠 Tools & Technologies Used
- SQL (MySQL)  
- Excel / CSV (Dataset)  

## 💡 Key Learnings
- Use of **Aggregate Functions** (SUM, AVG, COUNT)  
- Applying **GROUP BY** and **ORDER BY**  
- Writing **Subqueries** for deeper insights  
- Data filtering using **WHERE** clause
